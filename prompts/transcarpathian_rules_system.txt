## 1. Vowel Changes
### 1.1. Preservation of Archaic [ы]
The phoneme [ы] (a back vowel) is preserved as a continuant of Proto-Slavic and Old Ukrainian sounds.
Examples:
- "мити" → "мыти"
- "мило" → "мыло"
- "син" → "сын"
- "ситий" → "сытый"
- "яблуко" → "яблыко"
- "дрова" → "дрыва"
- "блоха" → "блыха"
- "гинути" → "гынути"
- "киснути" → "кыснути"
- "хитрий" → "хытрый"
### 1.2. [о] → [у] or [ÿ] in Newly Closed Syllables
In eastern and western subdialects: [о] → [у]
In central subdialects: [о] → [ÿ] (labializied [і])
Examples:
- "віз" → "вус" (eastern/western) / "вÿс" (central)
- "кінь" → "кунь" (eastern/western) / "кÿнь" (central)
- "стіл" → "сціл" / "сцюв"
### 1.3. [е] → [і] or ['у/'ÿ] in Newly Closed Syllables
Examples:
- "осінь" → "ôсінь"
- "приніс" → "принюс" / "прин'ус"
- "лід" → "люд" / "люд'"
- "мед" → "мнют"
- "тітка" → "т'ютка" / "т'ÿтка"
- "привів" → "привйух" / "прив'ÿх"
### 1.4. Preservation of [а] After Soft Consonants and Sibilants
Examples:
- "тягнути" → "тягнути" (preserved)
- "явір" → "явур" / "явÿр"
- "шапка" → "шапка" (preserved)
- "час" → "час" (preserved)
### 1.5. Open and Closed [о] Variants
Open [о] before syllables with [о], [а], [е]; closed [ô] before [і], [ÿ], [у] and soft consonants.
Examples:
- "око" → "око" (open)
- "корова" → "корова" (open)
- "в оці" → "в ôц'і" (closed)
- "корові" → "кôрôві" (closed)
- "кожух" → "кôжух" (closed)
### 1.6. Narrowing of [е] to [и] Before Soft Consonants
Examples:
- "перший" → "першый" / "піршый"
- "перші" → "пирші"
- "день" → "динь"
- "верх" → "вир'х"
### 1.7. Initial Stressed [о] → [у] or [ў]
Examples:
- "на горісі" → "на ўріс'і"
- "обійти" → "убыйти"
## 2. Consonant Changes
### 2.1. Preservation of Soft [р] and [ц]
Examples:
- "рябий" → "р'абый"
- "тепер" → "типир'"
### 2.2. Soft [ч] in Central and Western Subdialects
Examples:
- "чути" → "ч'ути"
- "чорний" → "ч'орний"
### 2.3. Pre-palatal [л] ("European l")
The consonant [л] has a pre-palatal character before all vowels.
Examples:
- "липа" → "липа" (with European l)
- "молоко" → "молоко" (with European l)
- "лавиця" → "лавиц'а"
- "лупати" → "лупати"
### 2.4. Absence of Prothetic Consonants
Many words lack the prothetic [г] before [о].
Examples:
- "вулиця" → "улиц'а"
- "вухо" → "ухо"
- "горіх" → "ôріх"
- "гострий" → "острый"
### 2.5. Secondary [н] After Historically Soft [м]
Examples:
- "сім'я" → "сімн'а"
- "м'яти" → "мн'ати"
- "ім'я" → "имн'а"
### 2.6. Secondary [л'] After Historically Soft [в] → [ў]
Examples:
- "здоров'я" → "здôрôўл'а"
- "кров'ю" → "крôўл'ôў"
### 2.7. Loss of [ў] Before [у/ÿ] from [о] in Newly Closed Syllables
Examples:
- "овес — вівса" → "овес — вÿса / уса"
- "вівця" → "вÿц'а" / "уц'а"
### 2.8. Nasal [ŋ] Before [к], [ґ]
Examples:
- "маленький" → "малиŋ'кый"
- "штахетина" → "шпаŋґл'а"
### 2.9. Africatization and Vocalization
Examples:

### 2.10. Assimilative Changes
- [ст'] → [с'ц']: "радість" → "радÿс'ц", "стягати" → "с'ц'ігати"
- [рл] → [лл]: "червоний" → "челленый", "терниця" → "теллиц'а"
- [дл] → [лл]: "поганий" → "пÿллый" / "пуллый"
- [дн] → [нн]: "піднімати" → "пуннімати", "полудень" → "пôлунне"
- [бм] → [мм]: "обмити" → "уммыти"
### 2.11. Historical [д] → [г] in Past Tense Verb Forms
In verb forms derived from Proto-Slavic clusters тл, дл.
Examples:
- "плів" → "плюг" / "пл'ÿг"
- "мів" → "мйуг"
- "привів" → "привйуг" / "привÿг"
- "пободав" → "збÿг"
